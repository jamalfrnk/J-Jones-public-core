# Security

Do not report vulnerabilities in a public issue. Use GitHub's private
vulnerability-reporting mechanism for this repository or contact the
maintainer through the security contact configured in the repository settings.

Never include credentials, private user content, provider responses, or
unredacted exploit material in an issue, pull request, or public discussion.

The alpha release is not a hosted service and does not accept production
secrets. Public runtime access requires explicit authentication at the
application boundary.
