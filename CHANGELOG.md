# Changelog

## 0.1.0-alpha.1 — 2026-11-17

Initial public-Core alpha release. This release contains generic note parsing,
untrusted-content fencing, provider-neutral contracts with explicit
authentication gating, local evidence hashing, and a rebuildable SQLite FTS5
index.

This alpha does not include private governance, identity, entitlement,
provider adapters, private migrations, commercial configuration, or hosted
services.
